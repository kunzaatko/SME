# Pizza Chains in Australia

This project analyses pizza size data from two Australian pizza chains, Dominos and EagleBoys, to evaluate claims from
a marketing campaign that Eagle Boys pizzas are larger than Dominos pizzas and that Eagle Boys large pizzas measure 12
inches in diameter.

The compiled PDF document is available in [releases](https://github.com/kunzaatko/SME/releases).
This is the latest version of the [document](https://github.com/kunzaatko/SME/releases/latest/download/protokol.pdf).

The analysis includes:
- Data preparation and cleaning
- Descriptive statistics
- Hypothesis testing
- Comparison of pizza sizes across different crust types and toppings

The project uses Julia for data analysis and generates diagrams comparing pizza sizes between the two chains.
